## 🔄 Organization Process

When you add PDFs to `literature/literature_dump/`, I will:

1. **Scan each PDF** - Extract title, abstract, keywords
2. **Analyze content** - Read full text, identify methods used
3. **Categorize** - Assign to most relevant subdirectory
4. **Track** - Maintain an index of what's where
5. **Summarize** - Extract key insights for your dissertation

## 📋 Workflow

```
literature/literature_dump/*.pdf 
       ↓ (I scan and sort)
literature/[topic-specific-folder]/
       ↓ (I create summaries and track progress)
literature/[topic-specific-folder]/[papername]_summary.md
```
